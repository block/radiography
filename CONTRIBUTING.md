Contributing
============

If you would like to contribute code to Radiography you can do so through GitHub by
forking the repository and sending a pull request.

When submitting code, please make every effort to follow existing conventions
and style in order to keep the code as readable as possible. Kotlin code is formatted with
[ktfmt][2] (Google style). Run `./gradlew ktfmtFormat` to format your changes; `./gradlew build`
runs `ktfmtCheck` and will fail on unformatted code. Please also make sure your code compiles by
running `./gradlew clean build`.

Before your code can be accepted into the project you must also sign the
[Individual Contributor License Agreement (CLA)][1].
